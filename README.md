# Vigyanprep API

Clean, production-ready backend for the Vigyanprep platform.

## Setup

1. Copy `.env.example` to `.env` and fill in the values.
2. Choose your database provider in `.env` (`DB_PROVIDER=mongodb` or `DB_PROVIDER=supabase`).
3. Run `npm install`
4. Run `npm run dev` to start in development mode.

## Docker

`docker-compose up --build -d`
